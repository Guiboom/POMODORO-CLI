# PomodoroCLI

Aplicação de terminal desenvolvida em Python baseada na técnica Pomodoro para auxiliar na gestão do tempo e aumentar a produtividade durante sessões de estudo ou trabalho.

## Sobre o Projeto

O PomodoroCLI foi desenvolvido como um projeto de aprendizado para praticar a criação de aplicações interativas no terminal utilizando Python.

O objetivo foi simular um sistema de produtividade baseado na técnica Pomodoro, permitindo controlar períodos de foco e pausas através de menus e cronômetros executados diretamente no console.

## Funcionalidades

* Início de sessões Pomodoro
* Controle de períodos de foco e pausa
* Menu interativo no terminal
* Registro de tarefas
* Histórico de sessões
* Estatísticas de uso (em desenvolvimento)

## Tecnologias Utilizadas

* Python
* Biblioteca `time`
* Biblioteca `datetime`
* Biblioteca `json`
* Biblioteca `os`
